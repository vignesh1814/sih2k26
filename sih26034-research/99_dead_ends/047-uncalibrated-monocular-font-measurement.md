## Summary
Attempting to derive absolute millimeter font height from standard 2D smartphone photographs without an external reference object failed. Variations in focal length, distance to subject, and perspective angle introduce > 40% error margins, making automated legal enforcement indefensible. The project must use physical reference markers (ID cards) or route font verification to Human-in-the-Loop.
