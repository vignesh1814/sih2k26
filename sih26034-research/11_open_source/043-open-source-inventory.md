## Why this source matters
Consolidates all selected open-source components, their repository URLs, star counts, licenses, and roles in SIH26034.

## Key extracted points
1. **PaddleOCR** (Apache 2.0, ~40k stars): Core text detection and recognition engine.
2. **RT-DETR** (Apache 2.0, ~6k stars): Principal Display Panel and barcode region detection.
3. **GoRules / Zen Engine** (MIT, ~3.5k stars): Decision-table execution engine for LMPC temporal rules.
4. **Outlines** (Apache 2.0, ~9k stars): Constrained token generation for Pydantic schema adherence.
5. **pyzbar / zbar** (MIT / LGPL-2.1): Standard 1D/2D barcode symbol decoding.
